Système modulaire M55

Trois cabinets de modules modélisés sur le System 55 : oscillateurs 921, filtre en échelle 904A, enveloppes 911, séquenceur 960, banc 914.

  • Glisse d’une prise à une autre pour tirer un câble.
  • Touche une entrée branchée pour la débrancher, ou glisse sa fiche ailleurs.
  • Tiens l’en-tête d’un module pour le déplacer ; × pour le retirer.
  • Potards : glisse vers le haut ou le bas, double-touche pour remettre à zéro.

Patcher

  • Câble : glisse d’une sortie (étiquette claire) vers une entrée, ou l’inverse. Une sortie peut alimenter plusieurs câbles ; une entrée n’en prend qu’un.
  • Débrancher : touche l’entrée. Pour déplacer une fiche, glisse-la depuis l’entrée ; lâchée à côté d’une prise, elle revient à sa place. Pour déplacer le bout côté sortie, maintiens la sortie un instant puis glisse.
  • Prises serrées : le câble s’aimante à la prise la plus proche ; les autres câbles pâlissent pendant que tu tires.
  • Modules : + Module ajoute à la première place libre (une rangée est créée si besoin). Glisse l’en-tête pour déplacer.
  • Tensions : 1 V/oct partout. Les enveloppes sortent 0 à 5 V : passe par l’atténuateur 995 pour doser. Une entrée 995 libre donne +5 V fixe.
  • Zoom : pincer à deux doigts ou − / +. Clavier d’ordi : A W S E D F T G Y H U J K, Z/X pour l’octave.
  • Hold : les notes restent tenues après relâchement ; la note suivante remplace les notes tenues, un accord joué ensemble reste ensemble. La pédale de sustain MIDI (CC 64) fait la même chose.
  • MIDI : les notes jouent le module 950 ; le module Q174 donne hauteur, gate, vélocité, CC, bend, horloge. Bouton MIDI : touche un potard puis bouge un contrôleur pour l’assigner (point ambré = assigné). Le MIDI web marche dans Chrome et Edge, pas dans Safari ni sur iPad.
